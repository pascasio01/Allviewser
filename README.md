# Allviewser

**Compañero Digital** — Proyecto Independiente  
**Autor:** Pascasio Emmanuel Reynoso Reyes ([@pascasio01](https://github.com/pascasio01))

Aplicación web local-first: conversación con modelos configurables, proyectos, memoria, tareas, archivos en sandbox, taller verificable y un módulo de comercio inmersivo en demo.
