# Avisos de terceros

Este proyecto utiliza software de terceros. Sus licencias pertenecen a sus respectivos titulares. **No se atribuye al fundador el código ajeno.**

## Dependencias principales (runtime)

| Paquete | Uso | Notas |
|---------|-----|-------|
| Next.js | Framework web | Vercel / contribuidores Next.js |
| React / React DOM | UI | Meta y contribuidores |
| Zod | Validación de esquemas | Colinhacks / contribuidores |
| uuid | Identificadores |uuidjs / contribuidores |

## Dependencias de desarrollo

TypeScript, ESLint, eslint-config-next, Tailwind CSS, Vitest, tsx, tipos de DefinitelyTyped.

## Tipografías

Fuentes servidas vía `next/font` (Google Fonts): **Syne** y **Figtree**. Respetar sus condiciones de uso.
